# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in ZeroCIDeploy, please do **not** open a public issue.

Instead, please report security vulnerabilities via GitHub's [Private Vulnerability Reporting](https://github.com/KCuppens/zerocideploy/security/advisories/new) or email `kobecuppens@hotmail.com`.

Include the following in your report:
- A description of the vulnerability and its potential impact.
- Affected component (`agent`, `hub`, `schema`, etc.).
- Steps or a minimal proof of concept to reproduce the issue.
- Any suggested fixes or remediations.

We will acknowledge receipt within 48 hours and work with you to coordinate a disclosure timeline once the vulnerability is addressed.
